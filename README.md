# GateWise v1.1 — Global Airport Finder

GateWise answers the airport question people actually have:

> Where do I need to go?

## Fixes from v1.0

- Fixed typing bug. Inputs no longer re-render after every character.
- Expanded beyond Barcelona.
- Added global airport search with major airports built in.
- Terminal field is now free text, so it supports T1, T2, T3, A, B, International, Tom Bradley, etc.
- BCN remains as a more detailed built-in airport guide.
- Saved trips still work.
- API-ready structure remains.

## Important

GateWise v1.1 is global airport guidance, not live flight tracking.

It does not yet fetch live terminal/gate/baggage data from a flight API. A later version can connect to a provider such as AeroDataBox, Aviationstack, Cirium, FlightAware, etc.
