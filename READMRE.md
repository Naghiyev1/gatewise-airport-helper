# GateWise v1.0 — Terminal-first Flight Helper

GateWise is not trying to be another generic flight tracker.

It answers the airport question people actually have:

> Where do I need to go?

## v1 scope

This version is Barcelona-first and works without an API key.

Features:
- Flight / airline / date form
- Departing / meeting someone / arriving modes
- Manual terminal selection
- Barcelona BCN T1/T2 guide
- Terminal inference hints for common airlines
- Smoking area notes
- Transport notes
- Departure checklist
- Arrivals / pickup checklist
- Saved trips
- API-ready planning page
- PWA-style static app

## Important

Terminal hints are not live aviation data. Always verify with official airline or airport information on the day of travel.

## Future API mode

A later version can connect to flight data providers to fetch:
- live terminal
- gate
- baggage belt
- delay status
- estimated / actual times

The app is already structured to support that.
